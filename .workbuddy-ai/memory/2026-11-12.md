# 2026-11-12

## Built ThickVox: truce.audio vocal thickener plugin (v0.1.0)

Scaffolded with `cargo truce new` (truce 6.3.0, Rust 1.99.1) and flattened into
the workspace root. CLAP + VST3 + standalone are default features.

Architecture:
- `src/dsp/delay.rs` — one shared power-of-two circular buffer, 4-point cubic
  (Catmull-Rom) fractional reads. Shared by all 8 voices (not one per voice).
- `src/dsp/pitch_shifter.rs` — granular / dual-delay-line micro pitch shifter.
  Two read heads half a sweep apart, equal-power sin/cos crossfade, zero gain
  exactly at each wrap. `cents_to_ratio` uses a 2nd-order Taylor expansion
  instead of `powf` in the hot loop. Grain = 12 ms, min delay = 2 ms.
- `src/dsp/voice.rs` — the ±3/6/9/12 cent, 10/24 ms, hard L/R 8-voice table.
- `src/dsp/filter.rs` — one-pole (backward Euler, algebraic coeff) HPF + high
  shelf for the wet Side chain only.
- `src/dsp/thickener.rs` — voice sum -> M/S encode -> Side HPF + 4 kHz air
  shelf -> Side *= Width -> decode -> Mix -> + dry. `Mid Only Wet` folds to Mid.
- `src/lib.rs` — 10 params (IDs pinned 0..9), bus layouts stereo + mono-in to
  stereo-out, `reset` sizes the delay line from `AudioConfig.sample_rate`,
  `tail` = 50 ms, `latency` = 0 (dry path is undelayed on purpose), built-in
  GridLayout GUI.

Important implementation gotchas learned:
- Generated `ParamId` enum variants come from **field names**, not the
  `name = "..."` attribute (e.g. `pan_spread` -> `PanSpread`).
- Every smoothed param must be `.read()` exactly once per sample in the plugin
  loop and shared across voices; reading inside the voice loop advances the
  smoother 8x too fast.
- `for_each_stereo_frame` fans a 1-channel bus into both frame inputs and drops
  output slots past the bus width — verified with the `channels(1)` driver test.
- `BoolParam` reads with `.value() -> bool`; `flags = "automatable | bypass"`
  works.
- Bash tool needs `export PATH=/bin:/usr/bin:...:$HOME/.cargo/bin:$PATH` —
  the session PATH omits /bin so shim shebangs (`/usr/bin/env sh`) fail.

Verification: `cargo clippy --all-targets -- -D warnings` clean; 20 DSP unit
tests + 8 host-level `truce_test::driver!` tests pass; `cargo test --features
rt-paranoid` confirms zero audio-thread allocations; `cargo truce build`
produces `target/bundles/ThickVox.clap` and `ThickVox.vst3` (7 MB each).
`truce-test = "6.3"` was added as a dev-dependency (docs say "2.0" — outdated).

## Follow-up: per-pair pan spread (replaces the global Voice Pan)

User posted a second "ready-to-compile" skeleton. Compiling it verbatim in a
scratch crate (`/tmp/thickvox-skeleton-check`) proved it does NOT compile:
unresolved `truce_gui_types::layout::label`, `init` missing `InitContext`,
two "cannot borrow *buffer as mutable more than once" errors from repeated
`buffer.io(...)`, and `delay_ms` computed but never applied. Its one useful
idea — four per-±cent-pair spread knobs — was folded into the working DSP
instead of replacing it.

Changes:
- `Settings::pan_spread: f32` -> `pair_spread: [f32; 4]` in `thickener.rs`.
  Added `pair_pan(spread)` (constant-power: `cos(a), sin(a)` with
  `a = (1-spread)*PI/4`), plus `last_pair_spread` / `pair_pan` caches on
  `Thickener` so trig only runs while a knob is moving. `clear()` resets the
  cache with NAN to force a rebuild.
- `src/lib.rs`: **retired param id 3** (global Voice Pan) — never reuse IDs.
  Added `pair1_spread`..`pair4_spread` at ids 10..13, `linear(0,1)`,
  `default = 1.0`, `smooth = "linear(20)"`, `group = "Pair Pan"`.
  All four `.read()` once per sample into the `pair_spread` array.
  GUI now has 4 sections (THICKEN / PAIR PAN / IMAGE / TONE & LEVEL);
  `GridLayout::build` derives column count from the widest section, so a
  4th section is valid.
- `truce-test` `.set_param(id, normalized)` takes a **normalized** value, not
  the engineering value. Confirmed at truce-test 6.3.0 `src/lib.rs:851`.

- Edge case fixed with the above: `Mid Only Wet` used to compute
  `mid * SQRT_2`, calibrated for hard-panned voices. Once pairs can be
  centred that drifts ~3 dB. It now uses an accumulated **un-panned**
  `voice_sum * FRAC_1_SQRT_2 * mix`, so Mid Only is level-stable and immune
  to the four spread knobs. Test:
  `mid_only_level_is_independent_of_pair_spread`.

Verification after the change: `cargo fmt --all`, `cargo check --all-targets`,
`cargo test --features rt-paranoid` (24 DSP unit + 10 host tests, all pass,
including zero-allocation check), `cargo clippy --all-targets --features
rt-paranoid -- -D warnings`, `cargo truce build` — all clean. New signed
bundles at `target/bundles/ThickVox.clap` / `.vst3` (7.0 MB each).
